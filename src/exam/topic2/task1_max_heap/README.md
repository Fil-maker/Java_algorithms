# Задача 2.1. Двоичная max-куча

Реализуйте двоичную кучу на массиве, в корне которой лежит **максимальный** элемент, и обработайте последовательность команд.

| Команда | Действие | Вывод |
|---------|----------|-------|
| `ADD x` | добавить число `x` | нет |
| `MAX` | показать максимум, не удаляя его | максимум |
| `POP` | удалить максимум | удалённое число |

**Нельзя** использовать готовые кучи и очереди с приоритетом (`PriorityQueue`, `heapq`, `std::priority_queue`, `std::make_heap` и другие).

## Ввод

В первой строке целое число `q`, количество команд.

В следующих `q` строках по одной команде.

## Вывод

Для каждой команды `MAX` и `POP` одно число в отдельной строке.

## Ограничения

- `1 ≤ q ≤ 100 000`
- `|x| ≤ 10^9`
- Команды `MAX` и `POP` не встречаются, когда куча пуста.
- В куче могут быть одинаковые числа.

## Пример

Ввод:

```
7
ADD 3
ADD 10
ADD 5
MAX
POP
POP
MAX
```

Вывод:

```
10
10
5
3
```

## Ожидаемая сложность

`O(log n)` на `ADD` и `POP`, `O(1)` на `MAX`.

## Подсказка

Для элемента с индексом `i` родитель имеет индекс `(i - 1) / 2`, а дети имеют индексы `2i + 1` и `2i + 2`.
