# Задача 2.2. Хеш-таблица с цепочками

Реализуйте хеш-таблицу, которая хранит пары «ключ — значение» и разрешает коллизии методом цепочек. Обработайте последовательность команд.

| Команда | Действие | Вывод |
|---------|----------|-------|
| `PUT k v` | записать значение `v` по ключу `k`; если ключ уже есть, заменить значение | нет |
| `GET k` | найти значение по ключу `k` | значение или `NONE`, если ключа нет |
| `DEL k` | удалить ключ `k`; если ключа нет, ничего не делать | нет |

Хеш-функция: `h(k) = k mod m`, где `m` — число корзин. Значение `m` выберите сами. Достаточно простого числа, большего максимального числа команд, например `100003`. Увеличивать таблицу при заполнении не требуется.

**Нельзя** использовать готовые ассоциативные контейнеры (`HashMap`, `TreeMap`, `dict`, `set`, `std::map`, `std::unordered_map` и другие). Массивы, списки и `std::vector` использовать можно.

## Ввод

В первой строке целое число `q`, количество команд.

В следующих `q` строках по одной команде.

## Вывод

Для каждой команды `GET` одна строка с ответом.

## Ограничения

- `1 ≤ q ≤ 100 000`
- `|k|, |v| ≤ 10^9`

## Пример

Ввод:

```
8
PUT 5 100
PUT -3 7
GET 5
PUT 5 200
GET 5
DEL 5
GET 5
GET -3
```

Вывод:

```
100
200
NONE
7
```

## Ожидаемая сложность

`O(1 + α)` в среднем на операцию, где `α = n / m` — коэффициент заполнения.

## Подсказка

Ключи бывают отрицательными. В Java и C++ остаток `-3 % m` отрицателен, поэтому номер корзины считайте как `((k % m) + m) % m`.
