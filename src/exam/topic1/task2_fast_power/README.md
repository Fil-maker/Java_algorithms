# Задача 1.2. Быстрое возведение в степень

Вычислите `a^b` по модулю `1 000 000 007`.

Показатель `b` очень большой, поэтому `b` умножений подряд не успеют выполниться. Используйте идею «разделяй и властвуй»:

- `a^0 = 1`
- если `b` чётное, то `a^b = (a^(b/2))^2`
- если `b` нечётное, то `a^b = a · a^(b-1)`

**Нельзя** использовать библиотечное возведение в степень (`pow`, `**`, `Math.pow`, `BigInteger.modPow` и другие).

## Ввод

В единственной строке два целых числа `a` и `b` через пробел.

## Вывод

Одно число: значение `a^b mod 1 000 000 007`.

## Ограничения

- `1 ≤ a ≤ 10^9`
- `0 ≤ b ≤ 10^18`

## Примеры

Ввод:

```
2 10
```

Вывод:

```
1024
```

Ввод:

```
2 1000000000000000000
```

Вывод:

```
719476260
```

## Ожидаемая сложность

`O(log b)`: `T(b) = T(b/2) + O(1)`.

## Подсказка

Произведение двух остатков может достигать примерно `10^18`. В Java и C++ используйте 64-битный тип (`long`, `long long`).
