# Задача 1.1. Сортировка слиянием

Реализуйте сортировку слиянием с нуля и отсортируйте массив целых чисел по неубыванию.

**Нельзя** использовать библиотечные сортировки (`Arrays.sort`, `sorted`, `list.sort`, `std::sort` и другие).

## Ввод

В первой строке целое число `n`, размер массива.

Во второй строке `n` целых чисел `a_i` через пробел.

## Вывод

Отсортированный массив в одну строку через пробел.

## Ограничения

- `1 ≤ n ≤ 100 000`
- `|a_i| ≤ 10^9`
- В массиве могут быть одинаковые числа.

## Пример

Ввод:

```
6
5 -2 9 1 5 0
```

Вывод:

```
-2 0 1 5 5 9
```

## Ожидаемая сложность

`O(n log n)` по времени: `T(n) = 2T(n/2) + Θ(n)`.
