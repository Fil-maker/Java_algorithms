# Задача 3.2. Алгоритм Дейкстры

Дан ориентированный взвешенный граф с неотрицательными весами рёбер. Найдите кратчайшие расстояния от вершины `s` до всех вершин с помощью алгоритма Дейкстры.

**Можно** использовать стандартную очередь с приоритетом (`PriorityQueue`, `heapq`, `std::priority_queue`).

## Ввод

В первой строке три целых числа `n`, `m` и `s`: число вершин, число рёбер и стартовая вершина. Вершины нумеруются от `1` до `n`.

В следующих `m` строках по три целых числа `u`, `v` и `w`: ребро из `u` в `v` веса `w`.

## Вывод

В одну строку через пробел `n` чисел: расстояния от `s` до вершин `1, 2, ..., n`. Для недостижимой вершины выведите `-1`.

## Ограничения

- `1 ≤ n ≤ 100 000`
- `0 ≤ m ≤ 200 000`
- `1 ≤ s, u, v ≤ n`
- `0 ≤ w ≤ 10^9`
- Возможны кратные рёбра и петли.

## Пример

Ввод:

```
5 6 1
1 2 4
1 3 1
3 2 2
2 4 5
3 4 8
4 1 1
```

Вывод:

```
0 3 1 8 -1
```

## Ожидаемая сложность

`O((n + m) log n)`.

## Подсказка

Расстояния могут достигать примерно `10^14`. В Java и C++ используйте 64-битный тип (`long`, `long long`).
