# Задача 3.1. Кратчайший путь в лабиринте

Лабиринт задан прямоугольной сеткой. За один шаг можно перейти в соседнюю по стороне клетку: вверх, вниз, влево или вправо. Через стены проходить нельзя.

Найдите минимальное число шагов от старта до цели с помощью поиска в ширину.

Обозначения клеток:

| Символ | Клетка |
|--------|--------|
| `S` | старт |
| `G` | цель |
| `.` | свободная клетка |
| `#` | стена |

## Ввод

В первой строке два целых числа `r` и `c`: число строк и столбцов.

В следующих `r` строках по `c` символов без пробелов.

## Вывод

Одно число: минимальное количество шагов или `-1`, если цель недостижима.

## Ограничения

- `1 ≤ r, c ≤ 500`
- Символы `S` и `G` встречаются ровно по одному разу.

## Примеры

Ввод:

```
4 5
S..#.
.#.#.
.#...
...#G
```

Вывод:

```
7
```

Ввод:

```
3 3
S#.
##.
..G
```

Вывод:

```
-1
```

## Ожидаемая сложность

`O(r · c)`: в графе `r · c` вершин и не более четырёх рёбер у каждой.
