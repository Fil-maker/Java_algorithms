# Задача 4.2. Q-learning по журналу опыта

Агент уже провзаимодействовал со средой, и весь его опыт записан в журнал. Каждая запись содержит пять полей:

- `s` — состояние до действия;
- `a` — выбранное действие;
- `r` — полученная награда;
- `s2` — состояние после действия;
- `done` — `1`, если эпизод на этом шаге закончился, иначе `0`.

Изначально вся таблица `Q` заполнена нулями. Обработайте записи журнала в заданном порядке, применяя к каждой формулу Q-learning:

```
Q(s, a) ← Q(s, a) + α · ( target − Q(s, a) )
```

Здесь `target = r`, если `done = 1`. Иначе `target = r + γ · max Q(s2, a')`, где максимум берётся по всем действиям `a'`.

После обработки журнала выведите таблицу `Q` и жадную политику. Жадная политика для каждого состояния выбирает действие с наибольшим значением `Q`. Если таких действий несколько, выбирается действие с наименьшим номером.

Случайность и симуляция среды в этой задаче не нужны.

## Ввод

В первой строке через пробел: целые числа `n` и `m` (число состояний и действий), вещественные числа `α` и `γ`, целое число `k` (число записей журнала).

В следующих `k` строках по пять значений через пробел: `s a r s2 done`. Значения `s`, `a`, `s2`, `done` целые, `r` вещественное. Состояния и действия нумеруются с нуля.

## Вывод

Сначала `n` строк по `m` чисел с тремя знаками после десятичной точки: строка `s` содержит значения `Q(s, 0), Q(s, 1), ..., Q(s, m-1)`.

Затем одна строка из `n` целых чисел через пробел: жадное действие для каждого состояния.

Числа таблицы считаются верными, если отличаются от правильных не более чем на `0.001`.

## Ограничения

- `1 ≤ n, m ≤ 100`
- `0 < α ≤ 1`
- `0 ≤ γ ≤ 0.99`
- `1 ≤ k ≤ 100 000`
- `|r| ≤ 100`

## Пример

Ввод:

```
2 2 0.5 0.9 3
0 1 -1 1 0
1 1 10 1 1
0 1 -1 1 0
```

Вывод:

```
0.000 1.500
0.000 5.000
1 1
```

Разбор примера:

1. `Q(0,1) = 0 + 0.5 · (-1 + 0.9 · 0 - 0) = -0.5`
2. `Q(1,1) = 0 + 0.5 · (10 - 0) = 5`
3. `Q(0,1) = -0.5 + 0.5 · (-1 + 0.9 · 5 + 0.5) = 1.5`

## Ожидаемая сложность

`O(k · m + n · m)`.

## Подсказка

В Java используйте `String.format(Locale.US, "%.3f", x)`, чтобы разделителем была точка, а не запятая.
