# Задача 4.1. Value Iteration в коридоре

Агент находится в коридоре из `n` клеток с номерами `0, 1, ..., n-1`. Клетка `n-1` терминальная: на ней эпизод заканчивается, и `V(n-1) = 0`.

В каждой нетерминальной клетке доступны два действия:

- **влево:** переход в клетку `s-1`; из клетки `0` агент упирается в стену и остаётся в клетке `0`;
- **вправо:** переход в клетку `s+1`.

При попадании в клетку `s'`, в том числе при повторном попадании в ту же клетку, агент получает награду `r[s']`.

Вычислите ценность каждой клетки методом Value Iteration. Начните с `V(s) = 0` для всех клеток и обновляйте ценности по уравнению Беллмана:

```
V(s) = max( r[s'] + γ · V(s') )
```

Максимум берётся по двум действиям, `s'` — клетка после действия. Остановитесь, когда за полный проход по клеткам ни одна ценность не изменится больше чем на `10^-9`.

## Ввод

В первой строке целое число `n` и вещественное число `γ` через пробел.

Во второй строке `n` вещественных чисел `r[0], r[1], ..., r[n-1]`.

## Вывод

В одну строку через пробел `n` чисел с тремя знаками после десятичной точки: `V(0), V(1), ..., V(n-1)`.

Ответ считается верным, если каждое число отличается от правильного не более чем на `0.001`.

## Ограничения

- `2 ≤ n ≤ 100`
- `0 < γ ≤ 0.99`
- `|r[i]| ≤ 100`

## Примеры

Ввод:

```
4 0.9
-1 -1 -1 10
```

Вывод:

```
6.200 8.000 10.000 0.000
```

Ввод:

```
3 0.5
2 0 0
```

Вывод:

```
4.000 4.000 0.000
```

Во втором примере выгоднее всего бесконечно упираться в стену в клетке `0`: `V(0) = 2 + 0.5 · V(0)`, откуда `V(0) = 4`. Из клетки `1` выгодно идти влево: `V(1) = 2 + 0.5 · 4 = 4`.

## Ожидаемая сложность

`O(n)` на один проход. Число проходов зависит от `γ`: чем ближе `γ` к `1`, тем их больше.

## Подсказка

В Java используйте `String.format(Locale.US, "%.3f", x)`, чтобы разделителем была точка, а не запятая.
