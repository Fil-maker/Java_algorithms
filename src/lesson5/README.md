# Практика 5. Градиентные методы на Python

К лекции 5 «Оптимизация в непрерывных системах. Градиентные и стохастические методы».
Презентация: [gradient_practice.pptx](gradient_practice.pptx). Слайды 3–12 — краткая теория
для тех, кто пропустил лекцию: производная и градиент, GD и SGD, Momentum, RMSProp (и поэлементные
g², √v, g / √v), Adam с разбором первого шага, backprop. Слайд 17 — линии уровня оврага
`x² + 50y²` с траекториями оптимизаторов из задачи 3.

Все файлы — чистый Python 3, без сторонних библиотек. Каждый запускается сам по себе:

```bash
python task1_gd_1d.py
```

| Файл | Что делаем | Что увидим |
|---|---|---|
| `task1_gd_1d.py` | Спуск по параболе `f(x) = (x − 3)² + 1` | lr = 0.5 — 1 шаг, lr = 0.9 — скачет, lr = 1.0 — застревает, lr = 1.1 — расходится |
| `task2_linear_regression.py` | `y = A·x + B` по 5 точкам из лекции: СЛАУ, GD, SGD | GD совпадает с точным ответом `A = 1.95, B = 1.15`, SGD — рядом, но с шумом |
| `task3_optimizers.py` | GD, Momentum, RMSProp, Adam в «овраге» `x² + 50y²` | GD ограничен lr < 0.02 (143 шага), остальные быстрее |
| `task4_neuron.py` | Один нейрон учит OR, backprop вручную | Цепное правило: `dL/dw = 2(a − y) · a(1 − a) · x` |
| `task5_memory.py` | Память под оптимизатор | `d = 10⁸`: SGD ≈ 0.8 ГБ, Adam ≈ 1.6 ГБ (как в лекции) |
